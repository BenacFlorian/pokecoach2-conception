# V1.0.6 — matchup_run_process_status

Adds PostgreSQL enum `core.matchup_run_process_status` and column `matchup_runs.process_status` (default `INITIAL`) for UI/backend pipeline progress. Values: `INITIAL`, `PENDING STATS`, `PENDING GAME SIMULATIONS`, `SUCCESS`, `ERROR`.

Trigger `matchup_runs_process_status_tr` keeps `process_status` consistent with run `status`. Terminal runs freeze `process_status`.
